# The Tower of Babel — Audio Asset List (Voices, Music, Sound Effects)

Target player: kindergartener (age 5–6). Most cannot read yet, so **every line of on-screen text must also be spoken aloud.** Voice narration is not optional for this audience — it is the primary way the game communicates.

---

## 1. Voice Actors Needed (3 voices)

| Role | Description | Approx. lines |
|---|---|---|
| **Narrator** | Warm, calm, "storybook" voice. Reads item facts, questions, answer choices, and feedback. | ~70 |
| **Explorer** (player) | Friendly, curious, slightly older-kid or young-adult voice. | ~12 |
| **Ziggurat Priest** | Proud, boastful, a little silly (not scary). Also speaks "gibberish" at the end. | ~14 |

One person can play all three if pitch/character is changed. Record dry (no music), 44.1 kHz, mono WAV; export to **.mp3** or **.ogg** for the web.

All tracks must loop cleanly. 16-bit / chiptune style to match the art. Keep volume soft — under the voice.

**Licensing note:** for every downloaded file, save the license + author in `CREDITS.md` so it can be shown on the game's credits screen.

---

## 6. Technical Specs for the Web Build

- Format: **.mp3** (128 kbps) for broad browser support, with **.ogg** fallback optional
- Voice: mono, normalized to −3 dB, trimmed silence
- Music: stereo, seamless loop points
- Total audio budget target: **under 15 MB** so the game loads quickly on Cloudflare Pages
- Player must tap the screen once before any audio plays (browser autoplay rule) — the "Tap the tower to begin!" title screen handles this
